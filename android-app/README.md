# android-app — SIH26168 Android application (Phase 10: base & sensors)

> **Not compiled yet.** This machine has no JDK, Gradle, Kotlin compiler or Android SDK.
> Every file here was written as source and reviewed by hand; the first build and the first
> `:core:test` run happen on the build machine. Treat build errors there as expected work.

## Build machine

- JDK 17, Android SDK Platform 35 + build-tools, (optionally) Android Studio
- The Gradle **wrapper JAR is not committed** (a binary we cannot generate here). Once:
  ```
  cd android-app
  gradle wrapper --gradle-version 8.11.1      # creates gradlew + gradle/wrapper/gradle-wrapper.jar
  ```
- Library versions in `gradle/libs.versions.toml` are the last ones known to the author;
  bump them on the build machine if resolution fails.

```
./gradlew :core:test            # pure-JVM unit + golden-vector parity tests (no Android SDK needed)
./gradlew :app:assembleDebug    # APK -> app/build/outputs/apk/debug/
```

`:core:test` reads the golden vectors from `../tests/regression/golden/` (generated by
`scripts/parity/generate_golden_vectors.py` from the Python reference), so run it inside the
monorepo checkout.

## Modules

| Module | Kind | Contents |
| --- | --- | --- |
| `:core` | Kotlin/JVM | the shared sample schema (`SensorSample.kt`, a port of `navcore.sensors.samples`: same limits, same validation), Android → schema mapping (`AndroidMapping.kt`), `ImuAssembler`, GNSS state machine (`GnssStateMachine.kt`, a port of `navcore.state.gnss_state`), `RateMeter`, `SimulatedOutage`, `positionConfidence`, `SessionLogger`, `TrackProjector`, `Display`, the `NavigationEngine` contract + `GnssOnlyEngine` placeholder |
| `:sensors` | Android lib | `SensorSource`: accelerometer, gyroscope, magnetometer, gravity on a dedicated `HandlerThread` → cold `Flow<ChannelSample>`; counted rejections and drops |
| `:gnss` | Android lib | `LocationManagerGnssSource` (GPS provider, **default**: GNSS only) and `FusedGnssSource` (optional; may blend Wi-Fi/cell, labelled per line) → `Flow<GnssEvent>` |
| `:app` | Android app | `AcquisitionService` (foreground, type `location`; independent collector coroutines feeding ONE processing coroutine), Compose `NavigationScreen` (track canvas, HUD, outage toggle) and `DiagnosticsScreen`, `OnnxLatencyProbe`, `NavigationRepository` |

### Assets bundled by `copyExportedModels`

- `models/`: the Phase 6 exports + model cards (`../models/exported`);
- `config/imu_noise.json`: measured process noise (`../reports/phase4`); without it the app
  falls back to the GNSS-only engine rather than run on invented noise;
- `roads/`: the offline road bundle, if exported beforehand:
  `python scripts/export/export_road_bundle.py` (Coventry: 13.2 MB; gitignored, ODbL).

## Recorded session format (`files/sessions/<UTC stamp>/`)

`manifest.json` (schema version, session start in UTC ms **and** elapsed-realtime ns, device,
app version, sensors available, GNSS source), `sensors.csv` (`t_s,channel,x,y,z,accuracy`, DEVICE
frame, raw), `gnss.csv` (`t_s` = fix epoch, `t_received_s`, degrees, `accuracy_m` = Android's
68 % radius, `withheld_by_sim`), `events.csv` (state transitions, outage toggles, rejected fixes).
Numbers are locale-independent, full precision.
